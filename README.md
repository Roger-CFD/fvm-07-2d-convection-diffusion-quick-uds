- Objective: This project solves the 2d convection and diffusion of temperature numerically.
- Methodology: Finite volume method with Quick scheme  for interior nodes and Upwind scheme for nearest neighbor boundary nodes. Both are used for convective flux discretization. Central differencing is used of diffusive flux discretization.
- Implementation: 3 Standalone python codes are provided. The code Quick_UDS is self-contained and include everything required for execution,with no separate parameter files or solver files needed. The other codes tabulate the results but you have to manually input the data for speed and péclet number for each speed case.
- Results: Five plots are provided, one for each velocity case ranging from 5 m/s to 300 m/s, along with an additional plot illustrating the failure of the numerical scheme at a velocity of 350 m/s. Two tables compare the coefficients of the discretized equations obtained using the upwind and QUICK schemes.
